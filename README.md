# KratosAgent for Android

Official signed Android installer downloads are available under Releases.

Download the latest APK and install it over your existing KratosAgent app.
Do not uninstall or clear app storage. Your saved settings and conversations
remain on your device. Once the public-update version is installed, use
Settings > App updates > Check for updates > Download update > Install update.
No GitHub account or token is needed. Android asks for installation confirmation.

This repository contains release installers and update metadata only.
It does not contain the private source repository, user conversations or API keys.
